Hermes Inbox Manager

Personal-account assistant · Setup in progress · Not a public mailbox service

A private inbox-assistance routine for its configured account owner. It is designed to identify recent messages needing attention, prepare proposed replies for review and track source-based follow-ups.

Requested access and purpose

  • Gmail: recent inbox conversations and recent actual sent replies, to understand requests and match the owner's writing style.
  • Calendar: the owner's upcoming primary-calendar events, to provide scheduling context.
  • Drive: only files explicitly relevant to current conversations, rather than an unrelated Drive audit.

The intended inbox window is the last seven days. Older messages may be used only as necessary context within a relevant recent conversation. Unreadable attachments, missing sources and incomplete retrieval must be disclosed.

Human control

The routine uses read-only Google operations. Proposed replies are not sent or created as Gmail drafts automatically. Sending mail, changing labels, modifying files or events, making commitments and making payments require separate approval.

Private operation

Processing source code, credentials and private records are not published on this site. The planned cloud runner and encrypted state are kept separately in private GitHub storage. Approved summaries are delivered to the owner's chosen private Telegram chat.

Cloud activation remains gated on authentication, privacy controls and end-to-end delivery verification. The model-authentication design is still being resolved; this page does not claim that the routine is operating.
