Privacy policy

Hermes Inbox Manager · Effective 6 October 2026 · Planned personal-account operation

This tool is intended only for its configured account owner. It is not offered as a service for other Google users. It is currently in setup; live cloud processing must not start until the stated activation checks are met.

Google data accessed

Planned inputs include the authenticated account identifier; recent Gmail message headers, bodies, labels and relevant attachments; recent actual sent replies for writing-style calibration; upcoming primary-calendar events; and explicitly relevant Drive file metadata or content. Draft messages are not treated as sent replies or commitments. Unrelated older mail and unrelated Drive files are outside the intended retrieval scope.

How information is used

Information is used to classify recent conversations, explain actions and deadlines using source evidence, prepare review-only reply proposals and track follow-ups. Google access is restricted to read-only operations. The tool does not automatically send mail, create provider drafts, change labels, modify events or files, make commitments or make payments.

Service providers and sharing

The planned model integration is OpenAI Codex through the owner's ChatGPT account. Relevant message, attachment, calendar and targeted-file text would be sent to that model for the requested analysis. This authentication design is still under evaluation. Any replacement model provider must be approved by the owner and disclosed here before activation.

GitHub would host the private runner, protected credentials and encrypted persistent state. Telegram would receive the approved report text and proposed replies in the owner's selected private chat. Data is not sold, used for advertising, or shared for unrelated purposes.

Training and limited use

The tool itself does not use Google data to develop or train general-purpose models. Activation is gated on the owner confirming that optional ChatGPT and Codex training/data-sharing controls are off; those account-wide controls remain owner-managed. Google API data is intended to be handled solely for this requested assistance under the Google API Services User Data Policy, including its Limited Use requirements.

Storage and retention

Persistent follow-up records, proposed drafts, source evidence excerpts and delivery receipts would be encrypted before storage in a private GitHub repository. Refreshed credentials would be kept only in protected secrets or encrypted state. Acquired raw mailbox payloads and private model query files are not intended for the public site or public source repository.

Encrypted earlier state versions can remain in private Git history. This design does not promise immediate hard deletion of past versions. Model and Telegram retention are also subject to those services' policies and the owner's account settings.

Owner controls and contact

The owner can stop scheduled processing, revoke Google or model access, disable the Telegram integration, remove stored credentials, or delete the private state repository and its encryption key. The owner should stop the routine if training/data-sharing controls are changed. Requests or corrections can be raised in the private assistant conversation used to configure this personal tool; no public support email address is published.

This website

This documentation site contains no mailbox content, credential values, private state, forms, analytics or application-added cookies. Its hosting provider, GitHub, may retain ordinary hosting/security logs under its privacy statement.

Updates

Material changes to provider, purpose, access or sharing require owner approval and updated disclosures before activation.
